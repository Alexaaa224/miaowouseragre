喂养日记隐私政策

适用于“喂养日记-宝宝喂养记录”1.0.0。更新日期：2026 年 10 月 10 日。

记录保存在设备上

宝宝昵称、可选生日、喂奶时间、奶量、亲喂时长、妈妈吸奶记录、备注、草稿和设置保存在你的设备上。应用无需注册，不提供业务联网、家庭同步或远程账号服务。开发者不收集、接收或出售这些数据。

小组件与提醒

主程序与桌面小组件通过设备内的共享存储读取喂养时间和提醒状态。你开启提醒后，应用向 iOS 请求通知或闹钟权限，由系统安排提醒。提醒文案不包含宝宝昵称和奶量。拒绝或撤销权限不影响记录与统计。

备份和主动分享

只有你主动导出、保存或分享时，CSV、完整 JSON 备份或反馈内容才会交给你选择的系统文件或分享服务。你可以选择本机文件，也可以选择自己使用的云盘或其他服务；这些服务如何处理文件，取决于你的选择和该服务的政策。反馈内容默认不附带日记。备份含有日记记录，请妥善保存。

设备的 iCloud 备份或电脑备份也可能保存本地应用数据，取决于你的系统备份设置。应用没有自行上传或同步日记的功能，开发者无法访问你的系统备份。

删除与恢复

你可以删除单条记录或在设置中清除全部本地数据。恢复完整备份会在设备内保留恢复前的数据备份，恢复后的提醒保持关闭。你主动导出或分享的副本需要在相应存储位置或服务中自行删除。没有远程账号或服务器端日记需要申请删除。

广告、分析和权限

应用没有广告、第三方分析 SDK 或跨应用跟踪，不请求位置、通讯录、相机或麦克风权限。通知和闹钟权限只在你开启提醒时申请，并可以在系统设置中调整。

适用人群与政策更新

应用供家长记录喂养信息，不面向儿童提供社交或在线内容。应用不会根据年龄、奶量或时长提供医疗诊断、治疗或营养方案。若将来的版本改变数据处理方式，将相应更新本政策与商店隐私说明。

联系反馈与政策网页

你主动通过支持邮箱联系我们时，我们会收到你提供的邮箱地址、问题描述和主动附上的资料，用于回复和处理该请求。请避免发送完整宝宝日记、备份文件、密码或其他无关私人信息。应用不会自动发送日记或附加备份。

本隐私政策与支持网页通过 GitHub Pages 提供。访问网页时，GitHub 会出于安全目的记录并保存访问者的 IP 地址，无论访问者是否登录 GitHub。相关规则见 GitHub 隐私声明。本页面不加载广告、第三方统计脚本或外部字体，不要求登录即可阅读。访问网页不会将设备内的宝宝日记上传至 GitHub；应用的记录、统计、小组件与提醒功能不依赖这些网页。
